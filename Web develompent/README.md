# Sugar Bakes Bakery Website

## 1. Project Description

Sugar Bakes Bakery is a website created to showcase a baking business. The website allows customers to view different baked products, learn about the bakery and contact the business.

## 2. Purpose of the Website

The purpose of this website is to advertise Sugar Bakes Bakery and make it easier for customers to discover our products and services.

## 3. Website Features

- Home page
- About Us page
- Products page
- Gallery of baked goods
- Contact page
- Navigation menu

## 4. Technologies Used

- HTML
- CSS
- JavaScript

## 5. How to Run the Website

1. Download or open the project folder.
2. Open the folder in Visual Studio Code.
3. Find the index.html file.
4. Right-click on index.html.
5. The website will open in your browser.

## 6. Website Design

The website uses a blue colour theme with an attractive and user-friendly layout.

## 7. Target Audience

The website is designed for customers who enjoy cakes, cupcakes, cookies and other baked products.
